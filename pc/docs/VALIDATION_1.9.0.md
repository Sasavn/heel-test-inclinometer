# Проверка комплекта PC 1.9.0 / STM32 1.6.0 / Tab5 1.8.5

Дата: 11.11.2026. Программные стенды, имитаторы и сборки проверены отдельно
от физического оборудования. COM/DFU, прошивка плат и натурные измерения
в этой работе не выполнялись.

| Проверка | Результат |
|---|---|
| Чистая MSVC Release x64 | 20/20 CTest, 0 ошибок; ui_shots 531 проверок |
| Чистая MSVC Release x86 | 20/20 CTest, 0 ошибок; ui_shots 531 проверок |
| Таблица импортов Windows 7 | Проверка x64/x86 прошла; физическая Windows 7 не использовалась |
| Реальный путь UI угломера на имитаторе | STM32/Tab5, выбор режима, оси, потеря/возврат головки, запись, экспорт и повторный импорт XLSX |
| SD/USB в приложении | Оба носителя скачаны раздельно, CRC проверены, отсутствие USB не подменяется SD |
| Обновление | Имитаторы STM32 DFU / ESP OTA, fresh status и блокировки; натурного обновления не было |
| M025 | Краткий и полный XLSX на обеих архитектурах, по 35 проверок; входы не изменены |
| XLSX/PNG | ZIP/структура, openpyxl, отсутствие error-ячеек, встроенные и внешние графики |
| Протокол производителей → PC | Реальные JSON/REL.CSV host-производителей STM32/Tab5 прочитаны рабочими C++-парсерами |
| Файлы прошивок → PC | Два STM32 BIN и четыре ESP BIN приняты проверкой своей платформы; чужая платформа отвергнута |

В первом параллельном прогоне x64 тест записи использовал общий с x86
временный каталог: две проверки имён файлов не прошли. Каталог теста
изолирован по процессу; link_test повторён на обеих архитектурах, 157/157.
Остальные 19 тестов прошли на окончательных чистых сборках. Производственный
код после этих сборок не менялся.

В M025 использованы девять ручных окон и условные параметры D/P/B. Это
проверка экспорта и отсутствия регрессии, а не результат натурного опыта h.

STM32: сборки default heel/level, 589 проверок приложения/SD и 524 CLI;
офлайн LVGL и 20 циклов меню/энкодера без роста занятой кучи. По map RAM
97680/131072, Flash 239844/393216 байт. Подробности в
[STM32_LEVEL_1.6.0.md](../../BWM427_Inclinometer/docs/STM32_LEVEL_1.6.0.md).

Tab5: четыре финальных профиля 1.8.5-esp32, capability явного SD/USB,
BIN↔ELF, SHA частей/manifest, ревизии P4 1xx/3xx и GPIO проверены.
Оценка собственных стековых кадров: default 3424/6144, controls 3456/6144.
Это статический guard, не измерение runtime stack high-water на плате.
Прежние неизменённые host-регрессии использованы повторно; финальные
производственные файлы проверены отдельно после последней capability-правки.

В GitHub восстановлены 14 доказанных архивных выпусков (17 оригинальных
файлов), без пересборки и перемещения прежних тегов. Все архивные и новые
assets скачаны после публикации и сверены по SHA-256. Исходники спорного
bundle v2.0.2 и версия его EXE разобраны в каталоге, история сохранена.

Остаются неподтверждёнными: работа нового комплекта на реальных платах,
электрическая схема и фактическая ревизия, головки/их точность, USB/DFU/OTA,
SD/USB, физические органы управления, динамический стек и метрологическая
пригодность. Системный диалог выбора папки не автоматизировался: запись
проверена через тот же программный путь приложения с явно заданной папкой.
