# Tab5 1.6.16: резерв внутренней RAM при запуске

23.10.2026 на P4 revision103/ST7121 выполнена запись 1.6.15 с подтверждением
ROM-MD5 всех четырёх частей и сохранением NVS. В аппаратной проверке обнаружен
ранний выход из `app_main()` после настройки подсветки, до запуска USB-протокола.
Это отличается от успешной компиляции и хостовых тестов 1.6.15: рабочий запуск
на устройстве ими не подтверждался.

Из внутренней статической RAM убраны TCP-буферы клиентов (103264 байта на P4).
Размеры буферов и число клиентов сохранены. Буферы выделяются явно в PSRAM
до создания задач; отказ выделения обрабатывается как ошибка core-init.
Очереди и стеки задач остаются во внутренней RAM, их размеры не уменьшены.
Асинхронное монтирование SD и запуск UI до обращения к носителям сохранены.

В ошибочном пути запуска добавлена диагностика `BOOTFAIL`: адрес вызывающего
кода, свободная внутренняя память, крупнейший непрерывный блок и свободная
PSRAM. В нормальном пути дополнительной печати нет.

На момент подготовки исправления плата была отключена от USB. Итог аппаратной
проверки и контрольные суммы кандидата сохраняются отдельно после пересборки.

Обе фактические сборки ESP-IDF 5.5.2 и пакеты 1.6.16 прошли проверку
descriptor/revision, отсутствия LVGL и FINE=0/TIMING=0. По реальным ELF
`clients` уменьшился со 103264 до 4 байт, внутренний BSS — на 103260 байт
в обоих профилях (`ram-delta.json`). Размеры содержимого TCP сохранены.

`host/HOST_GATES.json`: PASS. Проверены PSRAM|8BIT caps, начальное состояние
буферов, allocation failure без создания workers/consumers, повтор после
отказа и cleanup ранней ошибки core. Также прошли 14 deferred-сценариев,
legacy services, BSP, FatFs overlay и MSC getter. Большие бенчмарки
не повторялись: код отрисовки не менялся.

Кандидат доставлен в `C:\Tools\fw\tab5-native-1616-20261023` на целевом ПК.
Проверенный установщик сообщил `PREPARED … USB absent; not flashed`.
Это не подтверждение аппаратного устранения сбоя. Локальный архив двух
ревизий и SHA256 частей описаны в `packages.json`.
