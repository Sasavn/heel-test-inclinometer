# Tab5 1.8.9

Предварительный выпуск прошивки регистратора крена и угломера для M5Stack Tab5 с ESP32-P4.

## Угломер

- Разность строится из двух ответов одного прохода RS‑485. После переключения режима прошивка ждёт первую полную пару. Для неё действуют пределы возраста 500 мс и разноса 50 мс.
- Числа возраста и разноса на основном экране обновляются раз в секунду. Изменение качества пары отображается сразу.
- «Выравнивание» в левом меню теперь называется «Замеры углов». Эта подпись и «Качество пары» занимают две строки. Все пункты меню угломера используют жирный шрифт 24 px.
- Оценка качества пары, пояснение нуля и обозначения носителей стали контрастнее. Подписи «Исходные углы» и показатели памяти крупнее. Вместо PS в строке состояния указано «Доп. ОЗУ».
- Кнопка единиц показывает, в какой режим переключит экран. При показаниях в градусах кнопка подписана «мм/м». На странице «Наблюдение» есть «Зафиксировать» и «Снять фиксацию».

## Пакеты

Выбирайте ревизию процессора P4 и аппаратный профиль предыдущей прошивки. Для прибора с энкодером на GPIO 3/4, кнопкой на GPIO 2 и тумблером записи на GPIO 48 предназначен вариант `controls`.

| Профиль | P4 rev1.x | P4 rev3.x |
|---|---|---|
| Обычный, обновление по Wi‑Fi | `Tab5-1.8.9-P4-rev1-OTA.zip` | `Tab5-1.8.9-P4-rev3-OTA.zip` |
| Controls, обновление по Wi‑Fi | `Tab5-1.8.9-controls-P4-rev1-OTA.zip` | `Tab5-1.8.9-controls-P4-rev3-OTA.zip` |

Для обновления через приложение ПК распакуйте ZIP, оставьте `krenomer-esp32.json` рядом с `krenomer-esp32.bin` и выберите `.bin`. Пакеты без суффикса `-OTA` содержат комплект для установки через загрузчик. Контрольные суммы опубликованы в `SHA256SUMS.txt`.

Прошивка прошла проверки на ПК. Загрузка ЦП и фактическая частота опроса требуют замера на физическом Tab5.
