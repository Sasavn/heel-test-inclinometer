# Tab5 1.7.7: возврат прежнего сглаживания

После проверки 1.7.6 на экране оператор сообщил, что края букв стали хуже.
Квантизация покрытия до четырёх уровней отменена. native_ui.c восстановлен
из ad6aee1: прежние 16 уровней 4bpp-шрифтов, без изменений размеров и кернинга.
Оптимизации span/LUT и частичного PPA-поворота сохранены.

Сборка ESP-IDF 5.5.2, P4 rev100–199. SHA256 приложения:
`cbf7686527c65eb78b10b92a73b5d2bb6839a21bee3235ad514dcbcdb3478c72`.

Host-проверки: test_native_text_aa.py — 3840 draws, bpp1/2/4/8,
обе темы, opacity/clipping, исходная математика покрытия и fast/generic;
test_native_raster_cache.py — по 12014 bitmap checks в fine0/fine1.

На HASEE через mesh-replica прошивка записана с проверкой ROM-MD5 всех
четырёх частей, NVS сохранена. Плата P4 rev103/ST7121 запустила 1.7.7:
boot_confirmed=true, шесть status с uptime28–39с, RTC=true, WiFi STA
подключена. SD volume0 и USB volume1 имеют разные корректные ёмкости.

## Измерения предыдущей версии и ограничения

Две ручные прокрутки настроек, около 32 секунд каждая:

| Метрика | 1.7.4 | 1.7.6 |
|---|---:|---:|
| Средний refresh, мс | 123.168 | 95.043 |
| Средний render, мс | 49.529 | 46.324 |
| Средний rotate, мс | 45.363 | 20.447 |
| Средний wait, мс | 28.545 | 28.647 |
| Interactive renders | 98 | 100 |
| Ошибки вывода | 0 | 0 |

Это не измерение touch-to-photon и не контролируемое воспроизведение жеста.
Оператор сообщил, что по ощущениям интерфейс всё ещё тормозит; снижение
refresh на 22.8% не считается подтверждением исправленного отклика.
Проверка обработки касаний и ожиданий продолжается отдельно.

Последний автоматический NTP-запрос на 1.7.6 завершился тайм-аутом.
RTC и перенос времени с компьютера проверены ранее. Оптическую резкость
после возврата сглаживания должен оценить оператор.
