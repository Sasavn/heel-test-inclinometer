# Креномер Tab5: новый интерфейс, ТЗ для реализации в LVGL

Исходные материалы:
- `mockup.html` — макет. Открыть в браузере; переключатель темы вверху. Если открыть `mockup.html?shot=N&theme=dark`, получится один экран 1280×720 без полей.
- `png/` — эталонные кадры каждого экрана, светлая и тёмная тема (`*_light.png`, `*_dark.png`).
- `templates/` — образцы, которые прислал руководитель (С. А. Русановский).

Отзыв руководителя на текущий экран (22.10): «Плохой дизайн интерфейса. Воспользуйся цветовым вариантом приложения для ПК».
Он приложил образцы, их общие черты:
- тёмная боковая панель со значками и подписями;
- сверху крупный баннер;
- ниже карточки, у каждой заголовок со значком.

Этот макет — ответ на отзыв. Его надо перенести в `tab5/main/tab5_ui.c` (worktree `diplom_project_tab5`).

## 0. Границы

- Контракт `tab5_ui.h` не ломать. Действия уходят только через `tab5_ui_action_cb_t`. Проверку значений, сохранение, запись и сеть по-прежнему делает `main`. Новые поля состояния добавлять в конец `tab5_ui_state_t` с флагом `known` (см. §6).
- Исходную прошивку STM32 и программу ПК не трогать.
- Экран 1280×720, альбомная ориентация. Поворот выполняет `main`, как сейчас.
- Числа в макете синтетические.
- Десятичный разделитель — точка, как в программе ПК (`%.2f°`). Минус — типографский `−` (U+2212), у положительных углов знак `+`.

### 5.6 Цифровая клавиатура — `png/6_*`

- Затемнение экрана: `rgba(8,14,30,.55)`.
- Окно: (340, 52) экрана, 600 × 616, радиус 20.
- Заголовок 28 Bold; под ним «допустимо A–B ед · сейчас X ед».
- Табло: высота 80, значение 48 Bold, прижато вправо, единица 24 `muted`.
  - Рамка: `border`, если значение допустимо; 2 px `err`, если нет.
  - Под табло строка ошибки 17 `err`: «✗ больше 50 Гц — уменьшите значение».
- Клавиши 4 × 4, высота 64, промежуток 10:
  - 7 8 9 ⌫ / 4 5 6 ± / 1 2 3 C / 0 (двойная ширина) . «было»;
  - «было» возвращает текущее значение;
  - «.» только для дробных параметров;
  - «±» только там, где допустим минус (сейчас таких нет — клавишу можно отключить).
- Кнопки «Отмена» (ghost) и «Готово» (primary; неактивна, пока значение вне диапазона).
- «Готово» меняет значение степпера и помечает его изменённым. Применение — только кнопкой «Применить» на странице.

## 6. Какие данные нужны

Уже есть в `tab5_ui_state_t`, хватает для экранов 5.1, 5.4 и 5.5:
- `measurement.sensor[i]`: `x`, `y`, `roll_x/y`, `calm_x/y`, `valid`, `fail_streak`, `errors`, `last_error`, `zero_x/y`, `timestamp_us`, `roll_fill_s`;
- `measurement.stable`, `config`;
- `sd`, `usb` (`known`, `mounted`, `recording`, `failed`, `written`);
- `link`, `clock`, `panel`, `network`, `recording`, `light_theme`.

Добавить в конец структуры, каждое поле с флагом `known`; при `known == false` UI показывает «—»:
1. `rec_file[40]`, `rec_started_us` — имя текущего файла и время начала записи, для баннера и страницы «Запись».
2. `sd.free_bytes`, `sd.total_bytes`, `usb.free_bytes`, `usb.total_bytes` — свободное место.
3. `tcp_clients`, `tcp_peer[48]` — подключён ли ПК.
4. `recent[5] { name[40]; start_unix; duration_s; rows; media_mask; closed_ok; }` — последние записи. Заполнять при монтировании носителя и после каждой остановки записи; каждый кадр каталог не читать.
5. `fw_version[24]` — если его ещё нет в `panel`.

Время последнего обнуления и буфер графика хранить в самом UI, `main` их не касается.

## 7. Реализация в LVGL

- Стили создавать один раз (`lv_style_t`) и держать две палитры. Смена темы — перекраска стилей и `lv_obj_report_style_change(NULL)`, без пересоздания объектов.
- В `tab5_ui_update` менять текст только если строка изменилась: сравнивать с прошлой строкой, `lv_label_set_text` вызывать по факту изменения. Цифры углов обновлять не чаще 10 Гц.
- Страницы — отдельные контейнеры, переключаются флагом `LV_OBJ_FLAG_HIDDEN`. График обновлять только на видимой странице, но буфер пополнять всегда.
- Без прокрутки: все страницы помещаются в 720 px; `LV_OBJ_FLAG_SCROLLABLE` снять.
- Градиент баннера — `bg_grad`. Если он заметно тормозит — сплошной `nav` (`#103269` / `#0B2247`). Декоративные дуги баннера необязательны.
- Касания: у мелких объектов (чипы-переключатели серий) увеличить зону через `ext_click_area`, чтобы она была не меньше 56 px.
