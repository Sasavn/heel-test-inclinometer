# Tab5 1.6.4: индикаторы ресурсов, 22.10.2026

Внизу левой панели над часами добавлены три строки16px, y550/578/606:
ЦП — средняя загрузка двух ядер за последнюю секунду; ОЗУ — занятая доля
внутреннего 8-bit heap; PS — занятая доля PSRAM heap. Статические области вне
heap в ОЗУ не включаются. Для каждого пула отдельный знаменатель: большой
PSRAM не скрывает нехватку внутренней памяти. Неизвестные значения — «—».

FreeRTOS runtime stats используют esp_timer; снимаются только idle counters
двух ядер. Модульные дельты32bit учитывают переполнение. Это оконная оценка
task runtime с небольшой погрешностью границ переключения, не аппаратный
счётчик всех ISR. Сбор раз в секунду без обхода списка задач и динамических
выделений. Повторные неизменные label не invalidated. Существующий `status.cpu`
теперь заполнен; добавлен `memory` с used/total в байтах. Формат измерений не менялся.
